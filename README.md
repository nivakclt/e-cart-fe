# E-Commerce Application – Frontend

A responsive e-commerce web application built using React, providing product browsing, shopping cart, wishlist, and product management functionality.

## Live Demo

[View Live Project]-https://ecart-regex.vercel.app/

## Tech Stack

<p>
  <img src="https://skillicons.dev/icons?i=react,js,html,css,bootstrap,redux" />
</p>

- **Frontend:** React.js
- **Styling:** CSS, Bootstrap
- **State Management:** Redux Toolkit
- **Routing:** React Router
- **API Integration:** Axios, REST APIs

## Features

- Product listing and browsing
- Product search
- Shopping cart management
- Wishlist management
- API integration
- Pagination
- Responsive user interface

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd ecart
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
